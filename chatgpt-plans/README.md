# مقایسهٔ پلن‌های ChatGPT

تاریخ بررسی: **۱۸ اکتبر ۲۰۲۶ (2026-10-18)**

## قیمت و تفاوت اصلی

قیمت‌ها به دلار آمریکا و مطابق [مستند رسمی قیمت‌گذاری OpenAI](https://learn.chatgpt.com/docs/pricing) هستند. این منبع جزئیات Work و Codex را نیز پوشش می‌دهد؛ امکانات این محیط‌ها را نباید با امکانات بخش Chat یکسان فرض کرد.

| پلن | هزینهٔ ماهانه | تفاوت اصلی |
| --- | --- | --- |
| Free | رایگان | شروع بدون اشتراک پولی |
| Go | ۸ دلار | گزینهٔ اقتصادی شخصی |
| Plus | ۲۰ دلار | دسترسی Codex در وب، CLI و افزونهٔ IDE؛ امکان خرید اعتبار بیشتر |
| Pro | ۱۰۰، ۲۰۰ یا ۵۰۰ دلار | امکانات Plus؛ حالت Ultrafast در سطح ۵۰۰ دلاری |
| Business | سالانه: معادل ۲۰ دلار برای هر کاربر در ماه؛ ماهانه: ۲۵ دلار | حداقل ۲ کاربر؛ فضای کاری اختصاصی، SAML SSO و MFA؛ عدم آموزش با داده‌های کسب‌وکار به‌صورت پیش‌فرض |
| Enterprise | توافق با فروش | کنترل‌های پیشرفتهٔ دسترسی، گزارش‌های ممیزی و تنظیمات نگهداری و محل داده |
| Edu | توافق با فروش | گزینهٔ سازمانی آموزشی؛ جزئیات قرارداد باید بررسی شود |

منبع جدول: [Pricing — ChatGPT Learn](https://learn.chatgpt.com/docs/pricing).

## نکات مربوط به مصرف

- هزینهٔ API از اشتراک جداست.
- مصرف Work و Codex مشترک است.
- سقف استفاده به مدل و کار بستگی دارد؛ محدودیت هفتگی نیز ممکن است اعمال شود.
- دسترسی بعضی قابلیت‌ها تدریجی است.

منبع: [قیمت‌گذاری و محدودیت‌های مصرف](https://learn.chatgpt.com/docs/pricing).

## راهنمای انتخاب

پیشنهادهای زیر تحلیل کاربردی این سند هستند:

| وضعیت شما | گزینهٔ پیشنهادی برای بررسی |
| --- | --- |
| هنوز کاربرد مشخص و تکرارشونده‌ای ندارید | با Free شروع کنید و محدودیت‌هایی را که عملاً تجربه می‌کنید یادداشت کنید. |
| بودجهٔ محدودی دارید | Go را بررسی کنید؛ پیش از خرید، وجود ابزار موردنیازتان را در حساب خود ببینید. |
| برای کار شخصی مرتب استفاده می‌کنید | Plus را با حجم کار یک ماه واقعی ارزیابی کنید. |
| مرتب به سقف مصرف می‌رسید | هزینهٔ ارتقا به Pro را با خرید اعتبار اضافه و ارزش زمان صرفه‌جویی‌شده مقایسه کنید. |
| چند نفر با اطلاعات شرکت کار می‌کنند | Business را از نظر مدیریت اعضا و حفاظت داده بررسی کنید. |
| الزامات ویژهٔ امنیت، ممیزی یا قرارداد دارید | نیازها را مکتوب و برای Enterprise با فروش مطرح کنید. |
| برای دانشگاه یا مؤسسهٔ آموزشی خرید می‌کنید | شرایط Edu را متناسب با تعداد کاربران و نیاز مؤسسه استعلام کنید. |

## پیش از خرید چه چیزهایی را بررسی کنیم؟

۱. قیمت نهایی پرداخت، ارز، مالیات و دورهٔ صورتحساب را در حساب خود بررسی کنید.
۲. دسترسی به ابزارهای موردنیاز مانند فایل، تصویر، صدا و پژوهش را برای همان پلن و محیط استفاده تأیید کنید.
۳. برای تصمیم سازمانی، تعداد کاربران، مدیریت دسترسی و شرایط داده را همراه با قیمت بسنجید.
۴. نام مدل و سقف پیام را ثابت فرض نکنید؛ این موارد ممکن است تغییر کنند.

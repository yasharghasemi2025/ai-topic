# جدول دستورهای طراحی

| `/logo` | لوگوی مدرن و مینیمال |

| `/infographic` | چیدمان اینفوگرافیک تمیز |
| `/pattern` | پترن تکرارشونده یکدست |
| `/moodboard` | مودبرد زیبای برند |
